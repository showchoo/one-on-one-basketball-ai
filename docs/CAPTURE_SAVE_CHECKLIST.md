# v0.7.12: 撮影終了とデータ保存の確認手順

この修正は端末内にJPEG/ZIPが作成できたかを表示します。**Google Driveへのアップロード完了を自動検証する機能ではありません。**

## 実機チェック（短時間・撮り直し不要）
1. 新しいAPKでアプリを起動して「START」→「両方開始」を選び、「操作を閉じる」の状態でも **「■ 撮影終了」ボタン**と **「● 撮影中 xx枚」**が画面下に見えること。
2. 10秒程度撮影し、「■ 撮影終了」を押すこと。「書き込み完了を確認中…」から「✔ 端末にxx枚保存」「Drive保存は未確認」に変わること。JPEG書き込み失敗件数も撮影中に確認すること。
3. 画面下の「ZIPを共有」を押すこと。ZIP作成完了とZIPサイズが表示され、共有画面が開くこと。**共有をキャンセルしてもDrive保存完了とは表示しない**こと。
4. ZIPをGoogle Driveへ共有し、Drive側の一覧でファイル名・容量を確認すること。戻ってから新しい「START」を押すと確認ダイアログが出ること。未確認なら「戻る」を選び、上書きせずにZIPを再共有できること。
5. 別の新規撮影で5分経過または容量上限に達した場合、画像の書き込み完了確認後に「端末にxx枚保存」が出て、明示的なZIP共有が可能になること。
6. アプリを終了・再起動した場合、直近の撮影セッションが復元され、端末にあるJPEGから再びZIPを共有できること。復元してもGoogle Drive保存済みと表示しないこと。
7. 途中で「RESET」を押した場合も最後の保存数を確認でき、再撮影・新規STARTで前回のZIP未作成データを無言で失わないこと。

## 判定用イベント
- `TRAINING_CAPTURE_START`: 撮影開始
- `TRAINING_CAPTURE_STOP`: 手動停止後、書き込みワーカー完了
- `TRAINING_CAPTURE_AUTO_STOP` と `TRAINING_CAPTURE_AUTO_SAVED`: 自動停止と端末保存確認
- `TRAINING_ZIP_READY`: ローカルZIPの作成完了（Driveへの保存完了とは異なる）
- `TRAINING_ZIP_ERROR` / `TRAINING_CAPTURE_FINISH_ERROR`: 保存に問題がある可能性

撮影済みの元ZIPを削除・上書きしないでください。
