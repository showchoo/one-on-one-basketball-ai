# One-on-One Basketball AI — Android Prototype v0.1

Androidスマホ1台を三脚に固定し、ハーフコート1on1（1点/2点・10点先取）の自動スコア係を目指す試作です。
**green-reader-prototype とは完全に別プロジェクト**です。

## v0.1で入っているもの

- CameraXのリアルタイムカメラ表示（横画面）
- EfficientDet-Lite0（COCO）を端末内で実行
- `person` と `sports ball` を検出
- 2人を A / B として簡易追跡
- リング位置を1タップで校正
- 3Pラインを5点タップで校正
- ボールが「リングより上 → リング領域 → 下」に抜ける動きを得点候補として検出
- シュート直前のボール保持者を暫定的に得点者とする
- シューター足元と3Pラインの位置から 1点 / 2点を暫定判定
- 10点先取
- Android TextToSpeech による得点読み上げ（Bluetoothスピーカーへ通常の音声出力として流せる）
- 誤判定検証用の A+1 / A+2 / B+1 / B+2 手動ボタン
- 推論時間(ms)を画面表示
- GitHub Actionsでdebug APKを自動生成

## 想定端末

最初の実機は FCNT arrows We2 を想定しています。
負荷を抑えるため、AI推論は約180ms間隔（最大5〜6回/秒）、EfficientDet-Lite0、CPU 2 threadsです。
カメラプレビューは1280x720を要求しますが、端末側が対応解像度へ調整する場合があります。

## 最初の設置方法

1. スマホを横向きで三脚に固定。
2. ハーフコート側からリング方向へカメラを向け、リング、3Pライン、2人の足元ができるだけ同時に入るようにする。
3. `リング位置` → 画面上のリング中央をタップ。
4. `3Pライン` → 見えている3Pラインを左から右へ5点タップ。
5. BluetoothスピーカーをAndroidの通常設定から接続。
6. `START`。
7. A/Bの枠とボールの黄色い枠が追従するか確認。

## 重要: v0.1の限界

これは「商品版」ではなく、**arrows We2でリアルタイム認識が成立するか確認する技術プロトタイプ**です。

特に次はまだ弱いです。

- COCOの汎用 `sports ball` 検出なので、遠距離のバスケットボールを見失う可能性が高い。
- リング自動認識はまだなく、最初に1回タップして位置を与える。
- A/Bは顔認証ではなく位置の連続性で追う簡易方式なので、激しく交差するとIDが入れ替わる場合がある。
- 1点/2点は画面上の3Pラインを5点で近似するため、カメラ角度によって誤差が出る。
- 「ボールが上からリングを通過」の2D軌跡判定なので、リング手前を通過しただけのボールを誤検出する可能性がある。
- ファウル判定は未実装。

## v0.2でやること

実コートの動画/ログを集め、以下を優先します。

1. バスケットボール専用の軽量検出モデル（ball / rim / person）の学習
2. ボール軌跡の時系列フィルタ（速度・方向・消失補完）
3. リング自動検出
4. A/BのRe-ID強化（服装特徴＋移動軌跡）
5. 3Pライン自動認識またはコート4点キャリブレーション＋射影変換
6. 得点時だけ前後数秒を保存する検証クリップ
7. 誤判定ワンタップ訂正と学習用ログ出力
8. arrows We2で発熱/FPS/電池消費を計測し、自動的に推論頻度を調整

## ビルド

- Android Studio / JDK 17
- Android SDK 35
- minSdk 26

`app/build.gradle.kts` の `preBuild` で、TensorFlow公式配布の EfficientDet-Lite0 TFLiteモデルをダウンロードします。

GitHubでは `.github/workflows/build-apk.yml` が `app-debug.apk` をArtifactとして生成します。

## 技術メモ

CameraX 1.6.2 + TensorFlow Lite Task Vision 0.4.4 を使用しています。
モデルはCOCO学習済みEfficientDet-Lite0で、v0.1では `person` と `sports ball` のみ利用します。
